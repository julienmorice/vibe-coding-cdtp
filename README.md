# Vibe coding & ingénierie pédagogique

Présentation du webinaire de la Communauté des Talents Pédagogiques du 30 octobre 2026, par Julien MORICE (IMT Business School, service PracTice) : le vibe coding au service de l'ingénierie pédagogique et le PracTice Store.

En ligne : https://julienmorice.github.io/vibe-coding-cdtp/

## Navigation

- Flèches, Espace ou clic à droite / à gauche : slide suivante ou précédente
- F : plein écran · N : notes de l'orateur
- Les vidéos de démonstration viennent du Médiaserveur IP Paris

## Fichiers

- `index.html` : la présentation
- `assets/` : images, logos et QR codes
- `construire_versions.py` : génère une version autonome (images intégrées) et la version pour le lien privé claude.ai
